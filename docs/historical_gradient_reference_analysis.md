# 历史 batch 梯度 reference：定义、可行条件与反例

日期：2026-10-28。对应统一记录：`../DPCO_dev.md`，DPCO-0003。

性质：应用户要求进行的理论分析及候选定义，不是已批准实施的算法规格。本次不修改代码、配置或启动脚本，不运行训练。

## 1. 结论与证据状态

1. 以过去原始 batch 平均梯度的指数移动平均（EMA）作为 reference，是一个可定义、可解释、值得验证的候选。它借鉴的是 Adam 的一阶矩估计，而不是直接把完整 Adam 更新方向当成真实梯度。
2. 它可能降低 reference 的抽样噪声，并消除本批样本参与评价自身的直接耦合；同时引入参数变化导致的历史滞后。历史越长并不自动越好。
3. 仅更换 reference 不能保证原 SAGE 的整向量翻转优于 SGD。甚至 reference 与真实梯度方向极接近，也可能因为样本的正交分量被一并翻转而损害真实目标。
4. 原三定理的代数结论与带条件的局部结论，不因目前实验不佳而自动被否定；应撤回的是把它们不加条件解释为实际 SAGE-E/L 应当优于 SGD。
5. 更完整的研究链应为：历史 reference 的误差 -> 翻转对真实目标的收益 -> 有限步长影响 -> 实际轨迹与成本。不能只验证 reference 内积增益。

**用户报告，尚未在本次复核实验数据：** 在已有实验框架下 SAGE-E、SAGE-L 均低于普通 SGD；教授认为应考虑历史 batch 的 gradient mean，并报告 MNIST 上有效。用户补充：教授没有给出保留梯度的具体形式。因此本文的 EMA、时序和超参数均为本次分析提出的候选，不能归因成教授已验证的算法。

## 2. 原材料分别证明了什么

阅读材料位于项目根目录的 `SAGE_Proof_byProf/`，保留原文件名称和内容。

- `SAGE_Theorem1_Final.pdf`：任意固定 reference r 下，最大化 r 与聚合方向的内积，在独立标量权重约束 [-1,1] 下由逐样本 sign 取得最优。这是代数优化，不保证 r 代表训练目标。
- `SAGE_Theorem2_Web_Output_Exact.pdf`：明确令 r = ∇F(θ)，才将严格内积增益转成足够小步长下相对 SGD 的局部目标优势。
- `SAGE_Theorem3_Web_Output_FULL_FIXED.pdf`：同样令 r_t = ∇F(θ_t)，再加光滑性、梯度质量和二阶矩约束推导沿自身轨迹的累计上界。第 7 页已明确不能据此比较两条完整轨迹的最终损失。
- `SAGE_theoretical_framework_cn.pdf`：第 4 页已写出 reference mismatch 与真实目标迁移条件；第 2 页的历史错误样本梯度是在当前参数上重算，与缓存旧参数处的梯度不同。
- `2608.22522v1.pdf` 为 DIVE 背景论文，讨论验证集或批内 self-influence、带噪标签等设定。本次教授口述的 MNIST 算法细节不能从这些材料中确定。本文的新结论不借用其经验结果来保证有效。

以下推导主要针对固定训练目标 F（例如全训练集平均风险）。推广到数据分布风险需要另外处理训练/总体目标差异，不能与泛化保证混为一谈。

## 3. 统一记号与原理论的缺口

第 t 步开始的参数为 θ_t，样本梯度、原始 batch 平均和真实目标梯度为

\[
g_{t,i}=\nabla\ell(\theta_t;z_{t,i}),\quad
G_t=\frac1B\sum_i g_{t,i},\quad h_t=\nabla F(\theta_t).
\]

这里 t 从 1 开始；θ_t 是第 t 步更新之前的状态。为使推导清楚，先分析不带底层动量、预条件器或正则项的更新。

对于给定 r_t，严格负内积时翻转，零内积保持原贡献：

\[
w_{t,i}=\begin{cases}-1,&r_t^\top g_{t,i}<0,\\1,&r_t^\top g_{t,i}\ge0,\end{cases}
\quad S_t=\frac1B\sum_iw_{t,i}g_{t,i},\quad C_t=S_t-G_t.
\]

有精确恒等式

\[
\Delta_t=r_t^\top C_t
=\frac2B\sum_{i:r_t^\top g_{t,i}<0}|r_t^\top g_{t,i}|\ge0.
\]

但真实目标的一阶比较由另一个量控制：

\[
\Lambda_t=h_t^\top C_t,
\qquad
F(\theta_t-\eta S_t)-F(\theta_t-\eta G_t)
=-\eta\Lambda_t+o(\eta).
\]

因此 Δ_t>0 只说明更加服从 reference，Λ_t>0 才说明对真正目标有一阶优势。

批内 loss reference 是本批经验目标的梯度；对这个冻结目标，原局部推导可以成立，但它不等于整个训练集的梯度。误分类子集的 reference 对应冻结选择后的错误子集代理目标，还额外改变了目标权重。对这两个目标的改善不自动迁移到完整训练目标或测试精度。

另一个耦合来自

\[
G_t^\top g_{t,i}=\frac1B\|g_{t,i}\|^2
+\frac1B\sum_{j\ne i}g_{t,j}^\top g_{t,i}.
\]

样本参与构造评价自身的 reference，包含正的自项；这会影响估值，但不是证明方法必然无效的理由。采用历史 reference 主要消除该直接自项，不会自动获得正确的外部目标。

## 4. 推荐的最小 reference 定义

为单独检验“历史信息是否有帮助”，首先只更换 reference，保留原来的贡献规则作为候选 A。

初始化 m_0=0，选择固定 β∈[0,1)。第 t 步使用

\[
\boxed{
r_t=\begin{cases}
0,&t=1,\\[2pt]
\displaystyle\frac{m_{t-1}}{1-\beta^{t-1}},&t\ge2,
\end{cases}
\qquad
m_t=\beta m_{t-1}+(1-\beta)G_t.
}
\]

严格时序：

1. 在 θ_t 处计算当前样本梯度和未经修正的 G_t。
2. 读取已在本步之前形成的 m_{t-1}，生成 r_t；评分时将 reference 及权重视为固定量。
3. 使用 r_t 计算 q_{t,i}=r_t^T g_{t,i} 和候选 S_t。
4. 第一步或 r_t=0 时执行普通 SGD；其余步按待研究规则更新 θ_{t+1}=θ_t−η_t S_t。
5. 用本步在 θ_t 处算出的**原始 G_t**形成 m_t，供下一步使用。m_t 的计算不使用更新后参数或 S_t。

这里“原始”指原训练损失的 batch 平均梯度，未做 sign 编辑、裁剪、动量或优化器预条件，不因预测正确/错误而筛选。固定大小 B 时，每个 batch 的抽样权重一致；变长 batch 必须另外约定样本数权重。

不建议第一版把 S_t 写回记忆，因为这样会形成“参考决定翻转 -> 翻转结果强化参考”的反馈，失去它作为未经编辑目标梯度估计的解释。也不先对每批 G_t 单独归一化；平均单位方向与估计原目标梯度是不同的统计问题。

该 reference 只需要一个参数大小的持久向量，不必存所有历史梯度。β=0 对应上一批原始梯度；β=0.9 可作一个与 Adam 一阶矩默认值有联系的初始假设，但没有理论说明它在本任务最优。

**关于偏差修正：** 对 hard sign 规则，除以正数 (1−β^{t−1}) 不改变任何评分符号，因此不改变被翻转的样本。保留它是为了使 r_t 的量纲和幅值能够与 h_t 比较；不能把偏差修正本身说成 sign 判定更好的原因。

**关于一拍延迟：** 选择 m_{t−1} 是为了使 reference 在新 batch 抽样前确定，得到干净的条件分析；这不是断言使用包含 G_t 的 m_t 一定无效。Adam 自身使用当步梯度更新矩，目的与独立地评价当前样本不同。

## 5. 它具体借鉴了 Adam 的哪一部分

Adam 保存梯度的一阶 EMA 及平方梯度的二阶 EMA，再用两者之比产生实际更新。候选 A 只借鉴一阶 EMA 的跨批统计，不自动成为 Adam 优化器。

在原欧氏 SGD 更新 θ−ηS 下，reference 希望估计的是 h，而不是完整的 Adam 更新方向。直接使用 m/√v 作为 reference，会改变评分的坐标度量，并不自动更接近 h。

若以后另行研究明确的预条件更新

\[
\theta^+=\theta-\eta P_tS_t,
\]

且 P_t 是评分和更新时共同固定的对称正定对角矩阵，则一阶项为 h_t^T P_tS_t，oracle reference 是 P_th_t，对应估计可以是 P_tr_t。但这已经改变更新几何，需要重新证明，不能将它与“只换历史 reference”混在一个对照中。Adam 还涉及动量状态，因此不能仅凭这条预条件公式宣称已经覆盖完整 Adam。

文献关系：[Adam 原论文](https://arxiv.org/abs/1412.6980) 支持其矩估计结构；[STORM](https://arxiv.org/abs/1905.10018) 使用专门设计的动量变体实现方差缩减。普通 EMA 不会自动继承 STORM 的理论速率。

## 6. 历史平均的收益：降噪；代价：滞后

先看固定参数、IID batch 的理想模型 G_s=h+ξ_s，其中 ξ_s 均值零、二阶矩不超过 σ_G²。令 n=t−1，偏差修正 EMA 的权重为

\[
a_{t,s}=\frac{(1-\beta)\beta^{t-1-s}}{1-\beta^{t-1}},
\quad 1\le s\le t-1,\quad \sum_s a_{t,s}=1.
\]

则

\[
\mathbb E\|r_t-h\|^2
\le\sigma_G^2 A_n,\quad
A_n=\sum_s a_{t,s}^2
=\frac{1-\beta}{1+\beta}\frac{1+\beta^n}{1-\beta^n}.
\]

在 n 较大时，β=0.9 对应方差因子约 1/19，β=0.99 对应约 1/199。这是固定参数、适当独立噪声下的计算，不是实际自适应训练轨迹的无条件方差结论。若每批由 B 个独立样本平均且单样本噪声二阶矩为 σ²，可进一步取 σ_G²≤σ²/B；BatchNorm 等依赖会改变这个简化模型。

实际训练中，存下的 G_s 在旧参数 θ_s 处求得。精确分解为

\[
r_t-h_t=\underbrace{\sum_s a_{t,s}(G_s-h_s)}_{\text{历史抽样噪声}}
+\underbrace{\sum_s a_{t,s}(h_s-h_t)}_{\text{目标梯度的历史滞后}}.
\]

若 F 为 L-smooth，每步位移几乎必然满足 ||θ_{s+1}−θ_s||≤D，而且 G_s−h_s 是条件均值零、条件二阶矩≤σ_G²的鞅差，则由鞅差正交性及 L² 三角不等式有

\[
\left(\mathbb E\|r_t-h_t\|^2\right)^{1/2}
\le \sigma_G\sqrt{A_n}+LDK_n,
\]

\[
K_n=\sum_s a_{t,s}(t-s)
=\frac1{1-\beta}-\frac{n\beta^n}{1-\beta^n}.
\]

较长历史下 K_n≈1/(1−β)。β=0.9 的平均梯度年龄约 10 步，β=0.99 约 100 步。

因此增加 β 一方面降噪，另一方面可能放大滞后。以上使用 L² 三角不等式，未把适应轨迹中相关的噪声与滞后错误地当成独立量相加方差。

这个上界需要所述条件，D、L 也未在实际网络上估计；它给出研究取舍，不是 reference 已可靠的证书。训练早期、大位移阶段、学习率或梯度方向剧烈变化时，EMA 可能比当前 batch 更差。接近驻点时 ||h_t|| 变小，绝对误差不大也可能造成方向错误。

保存历史样本再在 θ_t 重算梯度，可以减少旧参数梯度的滞后，但增加计算；如果只保存错误样本，还保留目标选择偏差。它与这里缓存梯度的 EMA 不是同一算法。

尤其不能写成一个错误的等式：

\[
\sum_s a_{t,s}\nabla F_{B_s}(\theta_s)
\quad\not\equiv\quad
\left.\nabla_\theta\sum_s a_{t,s}F_{B_s}(\theta)\right|_{\theta=\theta_t}.
\]

左侧保存旧参数处的梯度，右侧需要在当前参数重算。历史 EMA 一般不能直接冒充某个固定历史损失在当前点的精确梯度，因此不能仅靠给它起一个 reference objective 的名字就套用原定理 2、3。

## 7. 可检验的理论命题：reference 要准确到什么程度

令 e_t=||r_t−h_t||。对整向量翻转，有

\[
\boxed{\Lambda_t=h_t^\top C_t
=\Delta_t+(h_t-r_t)^\top C_t
\ge\Delta_t-e_t\|C_t\|.}
\]

因此在 C_t≠0 时，一个充分条件是

\[
\boxed{e_t<\Delta_t/\|C_t\|.}
\]

它把“reference 够好”变成了相对于本步修正的定量要求，而不是只看 reference 与 h_t 的 cosine 是否接近 1。

若新 batch 条件无偏，记 E_t 为给定新 batch 抽样前全部历史后的条件期望，r_t 与 h_t 在该条件下固定，则

\[
h_t^\top E_t[C_t]
\ge E_t[\Delta_t]-e_t\|E_t[C_t]\|.
\]

这不需要 r_t 与 h_t 相互独立。它需要当前抽样相对于历史有相应的无偏性；无放回打乱、状态依赖抽样等不能自动套用 IID 结论。EMA 的误差二阶矩上界也不能直接变成每步 e_t 的确定上界，更不能未经论证就把它代入门槛宣称获得保证。

### 有限步长的严格补充

若 ∇F 为 L-Lipschitz，记 G=G_t、C=C_t，则从基线终点 θ−ηG 出发应用下降引理，得到

\[
F(\theta-\eta(G+C))-F(\theta-\eta G)
\le-\eta h^\top C
+L\eta^2\left(\|G\|\|C\|+\tfrac12\|C\|^2\right).
\]

理由是先使用 θ−ηG 处的梯度，再用 ||∇F(θ−ηG)−h||≤Lη||G|| 控制差异。因此若

\[
A=\Delta-e\|C\|>0,\qquad
0<\eta<\frac{A}{L(\|G\|\|C\|+\|C\|^2/2)},
\]

就有严格的同状态一步优势。这里假设 L>0、C≠0；C=0 时两者相同。这个充分阈值可能保守，实际网络中的 L 和 e 仍未知。

这是对两个实际终点差值的界，不是把两个单独的上界相减。共同 V_t 包络给出较好上界，不直接排列实际损失或不同训练轨迹。

### 有可靠误差上界时的评分安全条件

若另有真正成立的 ||r_t−h_t||≤ε_t，则只对满足

\[
r_t^\top g_{t,i}<-\epsilon_t\|g_{t,i}\|
\]

的样本翻转，可保证这些样本满足 h_t^Tg_{t,i}<0。实际 EMA 并没有自动提供 ε_t；经验方差或两次估计的一致程度也不是该确定上界。这个门槛是条件命题，不能当作已可部署的置信机制。

## 8. 反例：reference 非常接近也可能翻错

考虑二维样本损失 ℓ_i(θ)=||θ+g_i||²/2，在 θ=0 处令

\[
g_1=(-0.001,1),\quad g_2=(2.001,-0.98),
\quad F=(\ell_1+\ell_2)/2.
\]

于是 F 是 Hessian 为单位矩阵的光滑强凸目标，真实全批梯度为

\[
h=G=(1,0.01).
\]

令 r=(1,0)，其与 h 的夹角约 0.573°，cosine≈0.99995。由于 r^Tg_1=−0.001，整向量翻转会把 g_1 变成 (0.001,−1)，得到

\[
S=(1.001,-0.99),\quad C=(0.001,-1).
\]

结果是

\[
\Delta=r^\top C=0.001>0,\qquad
\Lambda=h^\top C=-0.009<0.
\]

甚至可以精确计算

\[
F(-\eta S)-F(-\eta G)
=0.009\eta+0.4910005\eta^2>0\quad(\eta>0).
\]

因此它对这个真实目标的每个正步长都劣于同状态 SGD。reference 的高 cosine 无法防止微小负投影触发大正交分量的翻转；“负内积”不意味着该样本的整个梯度都错误。

### 独立、无偏 reference 也不够

一维样本损失为 ℓ(θ;a)=(θ+a)²/2，P(a=4)=1/4，P(a=−1)=3/4。在 θ=0 固定状态下，h=E[g]=1/4。用独立同分布的另一份梯度作为 r，则 E[r]=h。

对于单样本批次，整向量翻转后 S=sign(r)|g|，从而

\[
E[S]=(1/4-3/4)(4/4+3/4)=-7/8<0.
\]

无偏梯度均值朝正向，编辑后的平均方向却朝负向。此例是“上一批独立梯度”的冻结参数分析，不能当作 β=0.9 的实际训练轨迹，但足以否定“历史或独立或无偏本身就保证正确”的推断。

## 9. 可选的另一条路线：只反射与 reference 平行的分量

这一节是**另一个理论候选 B**，会改变编辑规则；不属于只换 reference，也未获实施授权。提出它是因为上一节表明参考质量与编辑几何是两个不同问题。

将样本梯度分为 g=g_∥+g_⊥。q=r^Tg<0 时，原规则把两个分量一起取负；可改为仅把平行分量取反：

\[
\widetilde g_i=
g_i-2\frac{\min(r^\top g_i,0)}{\|r\|^2}r,
\qquad r\ne0.
\]

r=0 时令其等于 g_i。这个反射满足

\[
r^\top\widetilde g_i=|r^\top g_i|,
\qquad \|\widetilde g_i\|=\|g_i\|.
\]

所以同样获得 reference 投影增益和相同的样本二阶能量包络，但不再满足旧定理 1 的标量权重可行集；不能继续称其为该 box 优化问题的同一最优解。

聚合后

\[
\widetilde S=G+\kappa r,\quad
\kappa=\frac{2}{B\|r\|^2}\sum_{i:r^\top g_i<0}(-r^\top g_i)
=\frac{\Delta}{\|r\|^2}\ge0.
\]

因此真实增益变为

\[
\boxed{h^\top(\widetilde S-G)
=\frac{\Delta}{\|r\|^2}h^\top r.}
\]

只要 h^Tr>0 且 Δ>0，就有严格的一阶优势。相比整向量翻转，这里只需要 reference 与真实梯度成锐角，避免额外要求不可控的正交修正恰好有利。充分条件 e<||h|| 可保证 h^Tr>0，但 EMA 仍不自动保证它，尤其在梯度接近零或方向快速变化时。

从另一个角度，旧 C 满足 r^TC=Δ，反射后的修正是其平行分量

\[
C_{\parallel}=\frac{\Delta}{\|r\|^2}r.
\]

在所有满足 r^TC=Δ 的修正中，它拥有最小范数（柯西不等式），即保留同样 reference 增益而不附带正交扰动。这里的“最小”仅指这一个约束下的修正范数，不是所有优化目标或训练效果的全局最优性。

对上一节二维例子，该反射给出 \(\widetilde S=(1.001,0.01)\)，真实一阶增益为 0.001。这个例子解释几何差异，不是实验证明该候选优于所有方法。

若在整个分析区间内逐历史有 h_t^Tr_t≥0，当前 batch 条件无偏，F 为下有界 L-smooth，且 E_t[V_t]≤V，则

\[
E_t[F(\theta_{t+1})]
\le F(\theta_t)-\eta_t\|h_t\|^2
-\eta_t(h_t^\top r_t)E_t[\kappa_t]
+\tfrac L2\eta_t^2V.
\]

求和得到与旧累计定理类似的同阶界及条件非负增益项。成锐角假设、有限步长与二阶能量仍需验证；这个界不保证实际完整轨迹比 SGD 好。

与文献的关系：[PCGrad](https://arxiv.org/abs/2001.06782) 在多任务设置中用投影去除冲突分量，常见公式系数为 1；这里系数 2 是反射，不等同于原 PCGrad。这里是标准几何构造的分析，未做完整新颖性检索，不宣称新算法原创性。其代价与效果也尚未实验验证。

## 10. 下一步应验证什么，而不是先扩大方法

**优先顺序：** 首先固定候选 A 的 lagged raw-gradient EMA 定义，回答“仅历史 reference 是否改善了目标迁移”。如果拟保留整向量翻转，就必须面对第 8 节风险；若希望改善理论可解释性，可单独讨论候选 B，不应在同一次对照中悄悄同时更换 reference 与编辑规则。

建议未来获得实现授权后，先做少量固定状态诊断：

1. 固定来自训练集的审计 batch bank、增强与输入状态，定义同一个 F_A；必要时在训练态冻结初始模型 buffers，候选评估不提交新 buffers。其梯度 h_A 是有限 bank 的 oracle，不直接代表全数据或总体梯度。
2. 在同一参数和 batch 下比较当前 batch、历史 EMA 与 h_A 的误差和方向。对 hard flip 记录 Δ、C、Λ_A=h_A^TC、误翻样本及其投影裕量，不能只记录 cosine 和 Δ。
3. 计算 F_A(θ−ηS)−F_A(θ−ηG)，区分实际学习率与小步长极限。可作范数匹配的只读诊断，区分方向收益与单纯增加位移。固定状态比较不能直接代替整段训练结论。
4. 若历史 reference 的目标迁移可靠，再做少量完整训练；至少与普通 SGD、匹配记忆尺度的动量 SGD 比较。否则无法区分“历史平均本身的收益”和“样本编辑的额外收益”。各方法学习率需合理匹配调参预算，报告训练目标、测试效果与实际时间，而非仅单一最终精度。

若 oracle reference 在足够小步长下仍不符合相应恒等式/局部理论，应检查目标定义、评分空间、梯度计算与更新是否一致；若小步长成立而实际步长失败，是有限步长或几何问题；若同状态诊断好但完整训练不好，还需分析轨迹、状态和泛化。不能把所有失败都归因于 reference。
